# Financial ERP

محتاج أبني ERP كامل بنفس فكر وبنفس Functionality بتاعت Odoo Enterprise ( هام جدا ) ويكون بلغتين ( العربية والإنجليزية ) ويكون الألوان والديزاينز بتاعته كلها بالنفسجي ودرجاته مثل ألوان شركة STC السعودية وهيشتغل عليه حوالي 200 مستخدم أو أكثر سواء مستخدمين مالية بأكثر من صلاحيات ( محاسب – رئيس حسابات – مدير حسابات – مدير مالي – مراجع داخلي ) وطبعا هيكون فيه صلاحيات كتير لكل واحد بشكل تفصيلي حسب نطاق عمله وهيغطي الموديولات التالية :-

1)	الحسابات والمالية ( ودا هيكون أول موديول وهنشتغل الباقي بعدين زي ( المشتريات – المخازن – الموارد البشرية )

إستخدم حساب mohamed.elsheikh@alhayat.sa كأدمن وأعطيه جميع الصلاحيات بشكل كامل

أهم حاجه ان السيستم هيشتغل علي أكثر من فرع يعني أقدر أفتح فروع تحت نفس الكيان الأساسي

أهم حاجه هيكون فيه ربط وتكامل بين الموديولات وبعضها فيما يخص العمليات والأحداث طبقا لأنظمة ال ERP المعمول بيها في الأسواق المحلية والعالمية

ركز أن كل معاملة مالي هتحدث داخل السيستم هينتج منها قيود محاسبية هتروح لميزان المراجعة ( شوف الأننظمة المالية العالمية بتعمل إزاي وإعمل زيها زي أوراكل أو ساب أو أودو )

ومحتاج إعدادات الموديولات تكون كل موديول فيه إعداداته وبالنسبة للمستخدمين والصلاحيات تكون في شاشة منفصلة 

إعملي إعدادات عامه للشركة والنشاط والسجلات والفروع أقدر أدخل فيها بيانات الشركة أو أعملها

الموديولات دي هتشغل شركة متوسطة إلي كبيرة

ويكون فيه داشبورد محترفة عامة ويكون داخل كل موديول الداشببورد بتاعته المخصصة لأعماله

هنبدأ في تفاصيل الحسابات والمالية 
محتاج يغطي الأتي :-
•	الجزء الخاص بالعملاء ( الفواتير – إشعارات الإضافة – التحصيلات )
•	الجزء الخاص بالموردين ( الفواتير – إشعارات الخصم – السدادات )
•	مكني أقدر أعرف العملاء والموردين من شاشة واحدة وسميه Partner ومكني أعرف لكل بارتنر حساب عميل وحساب مورد ( زي أودو بالظبط )
•	الجزء الخاص بالبنوك ( ويكون فيه كل شي عن البنوك وعمل المصادقات والتسويات البنكية ) ونقدر نعرف أكتر من حساب بنكي وأكتر من وسيلة سداد وأكتر من وسيلة تحصيل )
•	الجزء الخاص بالأصول Fixed Assets وموديول الإهلاكات
•	الجزء الخاص بالتمويلات والقروض وهيكون فيه متابعة للقروض وسدادتها وكل شي عنها
•	الجزء الخاص بالحسابات ودا هيكون فيه القيود المالية وموازين المراجعة وكل ما يتعلق من القيود الناشئة عن العمليات المالية وفيها نقدر نعمل قيد مانوال وكل ما يخص القيود حتي تصل إلي ميزان المراجعة Trial Balance
•	الجزء الخاص بالتقارير المالية وهيكون فيه التقارير التالية
-	ميزان المراجعة
-	الميزانية العمومية
-	قائمة الدخل ( ويكون فيها علي مستوي مراكز التكلفة )
-	كشف حساب العميل أو المورد Partner
-	Aging Report كشف أعمار مديونيات العملاء والموردين
-	تقارير الضريبة ودا أقدر أعمل منه تقرير ضريبة القيمة المضافة الشهرية طبقا للعمليات المالية اللي بتم في العملاء أو الموردين
•	الجزء الخاص بالإعدادت الخاصة بموديول الحسابات
-	شجرة الحسابات وجواها أقدر أفتح حسابات أو أنواع حسابات
-	مراكز التكلفة ( أساسية وفرعية وفرعية --- مستويات بلا حدود )
-	شروط الدفع أو التحصيل
-	تعريف الحسابات البنكية
-	تعريف الضرائب وكل ما يتعلق بها
-	العملات المستخدمة
-	الفترات المالية
-	أنواع الدفاتر ( Journals )
